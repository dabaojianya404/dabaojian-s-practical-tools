[h1=概述]

这个模组为 MC 添加了一些实用的工具。

添加了一个清理树木的工具和一个清理花草的工具，以及一个平整工具和一个混合清理工具，你可以在工具一栏找到。

[h1=工具列表]

清理树木工具：这个工具右键可以清除选定范围内的树木，手持工具 Shift+鼠标滚轮可以调节选定范围，最大 256x256，清除完毕后会自动更新光照，这个工具可以不用亲自跑到树上右键，最远可以隔着 64 个格子使用，这个工具可以清除一些模组的树；

清除花草工具：这个工具右键可以清除选定范围内的花草，手持工具 Shift+鼠标滚轮可以调节选定范围，最大 256x256，同样的，最远可以隔着 64 个格子使用；

平整工具：这个工具可以清除选中的方块面前的 128x128x50 的区域，然后再在选定的 y 轴基准高度上放置一层草方块，手持工具 Shift+鼠标滚轮可以调整放置的高度；

混合工具：包含树木清理工具和清除花草工具的所有功能；

撤销：默认f7撤销上一步操作。可在按键绑定中更改。
