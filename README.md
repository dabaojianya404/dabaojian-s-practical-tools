这个模组为我的世界添加了一些实用的工具，添加了一个清理树木的工具和一个清理花草的工具，以及一个平整工具和一个混合清理工具,你可以在工具一栏找到它们。

- 清理树木工具：
这个工具右键可以清除选定范围内的树木，手持工具shift+鼠标滚轮可以调节选定范围，最大256*256，清除完毕后会自动更新光照，这个工具可以不用亲自跑到树上右键，最远可以隔着64个格子使用，这个工具可以清除一些模组的树。
  
- 清除花草工具：
这个工具右键可以清除选定范围内的花草，手持工具shift+鼠标滚轮可以调节选定范围，最大256*256，同样的，最远可以隔着64个格子使用。

- 平整工具：
这个工具可以清除选中的方块面前的128*128*50的区域，然后再在选定的y轴基准高度上放置一层草方块，手持工具shift+鼠标滚轮可以调整放置的高度，自1.1.3版本开始手持工具shift+上方向键/左方向键/右方向键可以调节破坏范围的高/长/宽。

- 混合工具：
包含树木清理工具和清除花草工具的所有功能。

- 撤销：
从1.1.2版本开始，默认f7撤销上一步操作。可在按键绑定中更改。

- 命令：自1.1.3版本开始，新增/dbjtools指令，用法:/dbjtools [玩家名称] undo  管理员可以用此指令撤销服务器内成员的操作。请注意，最多只能撤销最近10次操作！
  
- 注意：
  自1.1.2版本开始，模组需要fabric api作为前置模组！

  This mod adds some practical tools to Minecraft, including a tree-clearing tool, a flower-and-grass-clearing tool, a leveling tool, and a combined clearing tool,You can find them under the Tools section.

- Tree-Clearing Tool:
Right-clicking with this tool clears all trees within a selected range. While holding the tool, press Shift + scroll the mouse wheel to adjust the range, up to a maximum of 256×256 blocks. After clearing, lighting updates automatically. You don't need to climb up to the trees—this tool can be used from up to 64 blocks away. It also supports trees from other mods.

- Flower-and-Grass-Clearing Tool:
Right-clicking with this tool clears all flowers and grass within a selected range. While holding the tool, press Shift + scroll the mouse wheel to adjust the range, up to a maximum of 256×256 blocks. Like the tree tool, it can be used from up to 64 blocks away.

- Leveling Tool:
This tool clears a 128×128×50 area in front of the selected block, then places a layer of grass blocks at the chosen Y-axis base height. While holding the tool, press Shift + scroll the mouse wheel to adjust the placement height，Starting from version 1.1.3, you can adjust the destruction range's height/length/width by holding a tool and pressing Shift + Up/Left/Right arrow keys..

- Combined Tool:
This tool combines all the functions of the tree-clearing tool and the flower-and-grass-clearing tool.

- Undo: 
Starting from version 1.1.2, the default key F7 will undo the previous action. This can be changed in the key bindings.

- Command: Starting from version 1.1.3, a new /dbjtools command has been added. Usage: /dbjtools [player name] undo. Admins can use this command to undo actions of members on the server. Please note, you can only undo the last 10 actions at most!
 
- Note:
Starting from version 1.1.2, the mod requires Fabric API as a prerequisite!
